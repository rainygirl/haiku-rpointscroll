# R PointScroll

A native Haiku input filter for pointing-stick laptops such as the Sony VAIO
P. Hold the middle button and move the stick to produce vertical or horizontal
wheel events instead of moving the pointer. A middle click without movement is
preserved.

Build and install on Haiku:

```sh
chmod +x install.sh
./install.sh
```

Open **Preferences -> R PointScroll** to change speed, acceleration, direction,
horizontal scrolling, and the movement dead zone. See `README.ko.md` for the
full documentation.
